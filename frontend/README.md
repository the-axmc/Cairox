# Cairox Frontend

Landing page for Cairox (pixel‑Egypt aesthetic).

## Run
```bash
# start middleware first (simple mode by default)
cd ../middleware
npm run dev

# then run frontend
cd frontend
npm install
npm run dev
```

## Replace placeholder art
The current `src/assets/*.png` files are 1×1 placeholders. Replace them with your
pixel art for full visuals:
- `frontend/src/assets/queen.png`
- `frontend/src/assets/background_queen.png`
- `frontend/src/assets/background_pyramid.png`
- `frontend/src/assets/pyramid.png`
- `frontend/src/assets/crocodile.png`

The favicon is loaded from `frontend/public/favicon.ico`.
